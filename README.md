# 상상을 앱으로 — 바이브코딩 공방

> 열 번의 선택으로 나만의 앱을 설계한다 — 교육 박람회 부스용 2분 바이브코딩 공방 체험

- 체험: https://bin7335.github.io/vibe-taste/
- 서버·로그인·AI API 없음. 정적 파일만으로 동작하고, 한 번 열면 오프라인에서도 됩니다(PWA).

## 무엇을 보여 주나

관람객이 **열 번 고르고(9문항 + 이름)**, AI 터미널에서 코드가 쓰이는 장면(왼쪽: 생각 → 뼈대 → 분위기 → 주인공 → 코드 → 테스트)과 앱이 단계별로 조립되는 장면(오른쪽)이 7초간 나오고 **나만의 앱**이 완성됩니다. 진짜 바이브코딩은 이 선택을 "말"로 하는 것이라는 메시지를 결과 화면과 프롬프트 보기로 전달합니다.

| 질문 | 보기 |
|---|---|
| 1. 무엇을 만들까? | 놀이 · 공부 · 업무 · 예술 |
| 2. 어떤 앱? | 종류별 4개 + "AI가 골라줘" |
| 3. 분위기 | 우주 · 바다 · 숲 · 사탕 (색·배경·장식·단어·퀴즈 문제가 바뀜) |
| 4. 주인공 | 로봇 · 고양이 · 공룡 · 유령 (말풍선 멘트) |
| 5. 속도 | 느긋하게 · 보통 · 빠르게 · 미친 속도 (게임 속도·문항 수·제한 시간) |
| 6. 말투 | 다정하게 · 장난스럽게 · 코치처럼 · 로봇처럼 (주인공 멘트) |
| 7. 효과음 | 띵동 · 8비트 · 조용한 소리 · 없음 |
| 8. 크기 | 큼직하게 · 보통 · 아기자기하게 (글자·버튼 배율) |
| 9. 축하 효과 | 색종이 팡팡 · 살짝 반짝 · 차분하게 |
| 10. 앱 이름 | 자유 입력(12자, 금지어 필터) 또는 AI 작명 |

앱 틀 16종
- 놀이: 반응속도 게임 · 피하기 게임 · 짝 맞추기 · 두더지 잡기
- 공부: 퀴즈 · 타자 연습 · 낱말 카드 · 암산 연습
- 업무: 사다리타기 · 뽑기 · 모둠 짜기 · 체크리스트 (타이머는 보기에서 뺐고, 이미 나간 QR로만 열립니다)
- 예술: 그림판 · 미니 피아노 · 비트 메이커 · 픽셀 아트

16틀 × 4테마 × 4캐릭터 × 4단계 + 시드 변주 = 매번 다른 결과.

결과 화면 버튼
- 📱 **폰으로 가져가기**: 선택값·시드를 주소에 담아 QR 생성(서버 저장 없음). 폰에서 열면 똑같은 앱.
- 🔁 **하나만 바꾸기**: "배경만 바다로 바꿔 줘" 체험. 시드·이름은 유지한 채 다시 코딩.
- 🧾 **코드 보기**: 방금 화면에 흐른 코드를 줄 번호·색 구분과 함께 다시 보고 복사(체험용으로 간추린 코드).
- 💬 **프롬프트 보기**: 선택을 말로 풀어 쓴 프롬프트(교사용) + 복사.
- 🏠 처음부터.

## 부스 운영 팁

1. 부스 기기(태블릿·노트북)에서 한 번 접속해 두면 와이파이가 끊겨도 동작합니다(서비스워커 캐시).
2. 결과 화면의 QR은 관람객 데이터로 열리므로 부스 인터넷과 무관합니다.
3. 키보드 A·B·C·D(1-4)로도 고를 수 있어 노트북 시연이 빠릅니다.

## 디자인

[Nutlope/hallmark](https://github.com/Nutlope/hallmark)의 Hum 테마(크림 종이·잉크·배 노랑 액션·눌리는 카드스톡)를 앱 화면 범위로 적용했습니다. 보라 그라데이션, 이모지 아이콘, 카드 속 카드, 헤드라인 속 한 단어 강조 같은 "AI가 만든 티"를 걷어냈고, 셸의 모든 색·글꼴은 `css/app.css` 상단 토큰으로만 씁니다(스탬프·면제 사유는 파일 첫 네 줄). 체험자가 고르는 4가지 분위기는 결과 무대(`.stage`)의 `--p-*` 변수로만 들어갑니다. 웹폰트는 오프라인 운영 때문에 일부러 싣지 않았습니다.

## 개발

```bash
python -m http.server 8765 --bind 127.0.0.1   # 로컬 미리보기 (ES 모듈이라 file:// 불가)
node tests/run.mjs                              # 헤드리스 크롬 자동 테스트 27개
```

구조
```
index.html            화면 뼈대
css/app.css           스타일
js/main.js            흐름 제어(질문 → 연출 → 결과), URL 상태, 바꿔보기
js/data.js            보기·테마·캐릭터·난이도·단어·퀴즈 데이터
js/build.js           터미널 연출(대본·미리보기 조립), 교사용 프롬프트 생성
js/mascot.js          공방 도우미 캐릭터(자체 제작 SVG)와 동작 상태
js/share.js           QR·코드 보기·프롬프트 모달
js/qr.js              QR 인코더(의존성 없음)
js/templates/*.js     앱 틀 17종: 선택 16 + 예전 링크용 타이머 (mount(root, ctx) → destroy)
sw.js                 오프라인 캐시
```

새 앱 틀 추가: `js/templates/<slug>.js`에 `export default function mount(root, ctx)`를 만들고 `templates/index.js`, `data.js`의 `APPS`·`KINDS`, `build.js`의 `SNIPPETS`, `sw.js` 캐시 목록에 등록.

## 보안·개인정보

- 사용자 입력(앱 이름, 뽑기 이름)은 화면에 `textContent`로만 넣고, URL에서 온 값은 허용 목록으로 검증합니다.
- 저장하는 데이터 없음(localStorage 미사용). 외부 요청 0 — 테스트가 검사합니다.
